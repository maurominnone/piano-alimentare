# Ogni giorno — Piano alimentare v2

Web app statica responsive, senza server e senza database.

## Pubblicazione su GitHub Pages

1. Crea un repository GitHub.
2. Carica **il contenuto** di questa cartella nella root del repository.
3. In **Settings → Pages**, scegli **Deploy from a branch**, branch `main`, cartella `/ (root)`.
4. Attendi la pubblicazione all’indirizzo `https://NOMEUTENTE.github.io/NOMEREPOSITORY/`.

## Funzioni

- Vista giornaliera con cinque momenti alimentari e check dei pasti.
- Menù settimanale personalizzabile per pranzo e cena.
- Sostituzioni con porzioni riportate nel piano.
- Regole e frequenze settimanali.
- Lista della spesa orientativa (non calcolata in grammi).
- Memorizzazione locale con `localStorage`.

## Note importanti

Il piano originale del 23 ottobre 2026 è la fonte autorevole. Le scelte personalizzate non vengono validate automaticamente; non vengono inventate grammature o equivalenze mancanti. Il PDF originale non è incluso per privacy. Il codice non invia dati a server; il font Google è una risorsa esterna opzionale.
